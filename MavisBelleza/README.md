# 💅 MavisBelleza - Sistema de Gestión de Turnos

Aplicación web interactiva desarrollada con **Blazor Server (.NET 8)** para la reserva y gestión de turnos en un centro de estética especializado en **Lifting de Pestañas**, **Laminado de Cejas** y **Perfilado de Cejas**.

---

## 🛠️ Tecnologías Utilizadas

* **Framework:** Blazor Server (.NET 8)
* **Base de Datos:** SQLite con Entity Framework Core (`IDbContextFactory`)
* **Diseño:** Bootstrap 5 (Responsive / Mobile-First), CSS Isolation & Tema Verde Botánico / Spa
* **Interoperabilidad:** JavaScript Interop (`IJSRuntime` para alertas globales)
* **Control de Versiones y CI/CD:** Git (Conventional Commits) & GitHub Actions
