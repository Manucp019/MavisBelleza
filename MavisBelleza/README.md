# 💅 MavisBelleza - Sistema de Gestión de Turnos

Aplicación web desarrollada con **Blazor Server (.NET 8)** para la reserva y gestión de turnos de un centro de estética.

## 🛠️ Tecnologías Utilizadas

* **Framework:** Blazor Server (.NET 8)
* **Base de Datos:** SQLite con Entity Framework Core (`IDbContextFactory`)
* **Diseño:** Bootstrap 5 (Responsive / Mobile-First) & CSS Isolation
* **Interoperabilidad:** JavaScript Interop (alertas globales)
* **Control de Versiones:** Git con Conventional Commits & GitHub Actions
